## What this shows (and does not)
- **Text PDFs:** every header field and line item correct on this synthetic set.
- **Scanned images (OCR):** most errors are character misreads (e.g. `CI` read as `C1`, wrong letter case),
  and some wrong values are **not** flagged for review (including one wrong currency). Scanned documents
  therefore always need human review, which the API already requires (`review_required: true`).
- Two defects were found by this benchmark and fixed before these results: the supplier label was
  returned with the name (`Seller: X`), and the scorer itself mis-normalised quantities.
- **Not a real-world accuracy figure.** Real supplier invoices have logos, merged cells, wrapped rows,
  stamps and handwriting. Measure real accuracy with permissioned, redacted invoices and
  `scripts/benchmark_invoices.py` (see `benchmarks/README.md`). Do not quote these numbers to customers.
